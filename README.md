## Project Overview
This repository contains a functional 2D game prototype developed using **Godot Engine 4** and **GDScript**. The project was built as a hands-on technical benchmark to evaluate modern game engine iteration speeds, node-based component architectures, and rapid-prototyping workflows against legacy engine paradigms (such as Unity/C#).

---

##Key Learnings & Engineering Metrics

* **Node-Based Scene Tree Architecture:** Analyzed how Godot's scene inheritance model simplifies state management and object coupling compared to traditional component-component models.
* **Rapid Prototyping Velocity:** Evaluated developer feedback loops, measuring a significant reduction in compilation overhead and asset pipeline configuration times during early-stage prototyping.
* **Scripting Efficiency:** Implemented core gameplay mechanics (player movement, collision detection, and state machines) using GDScript, testing dynamic typing against explicit type hints for rapid feature testing.

---

## Core Gameplay Features
* Dynamic 2D Player Controller with custom physics handling.
* RigidBody / Area2D collision checks and signal-driven event loops.
* Modular scene instantiation for dynamic asset spawning.
